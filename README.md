🎓 Tuition Management System

A full-featured web-based Tuition Management System developed using PHP and MySQL.  
This system helps manage students, teachers, classes, exams, assignments, attendance, and payments efficiently.

 🚀 Features
 
 👨‍🎓 Student Module
- View dashboard with notifications
- Access exam results with grades
- View assignments and learning materials
- Track personal performance
- Receive exam and result updates
- 
 👨‍🏫 Teacher Module
- Create and manage quizzes
- Upload assignments and materials
- View student submissions
- Assign marks for assignments and quizzes
- Generate student performance reports

 👨‍👩‍👧 Parent Module
- View child's academic progress
- Check exam results and grades
- Monitor performance using registration number

 🏫 Admin / Reception Module
- Manage student and teacher records
- Schedule exams and notify students
- Track attendance by class and month
- Handle student payments
  - Card payments (auto-approved)
  - Bank transfer (manual approval with slip view)

📊 Key Functionalities

- ✅ Exam result management with grading system  
- ✅ Assignment submission and marking system  
- ✅ Quiz creation and reporting  
- ✅ Attendance tracking  
- ✅ Payment management system  
- ✅ Notification system for students  
- ✅ Role-based dashboards (Student, Teacher, Parent, Admin)  

 🛠️ Technologies Used

- Backend: PHP (Core PHP), Python(for getting user feedback).
- Database: MySQL
- Frontend: Bootstrap
- Server: XAMPP (Apache)
